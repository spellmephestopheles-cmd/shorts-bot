# Short Script Writer

Channel: **Explained.** — unravels concepts in and around the world through storytelling. A Short answers **one** curious question in under 60 seconds and makes the viewer want to watch it again.

## Step 0 — Inputs (ask only if missing)
- Topic, news item, or the long-form script to cut from
- Length (default 45 s ≈ 110–120 words at ~150 wpm; hard max 60 s ≈ 150 words)
- Language (default English; Hinglish if asked)

## Step 1 — Pre-writing (show briefly before the script)
1. **The paradox in one line.** The strangest true contradiction in the topic. If there isn't one, find a better angle.
2. **The real explanation in one line.** What resolves the paradox.
3. **The twist.** One extra surprising fact that lands after the explanation. It must be true and must not repeat the paradox.
4. **Fact sheet.** Every number and claim with a source; flag anything unverified. Never invent facts. If a fact is reported but not confirmed, say "reportedly" or "may" on screen.

## Step 2 — The 4-part formula

| Part | Time (45 s Short) | Rules |
|---|---|---|
| **1. The Paradox** | 0–3 s | Open on a bizarre or contradictory statement. No greeting, no intro, no "In this video". First word does work. Say it in ≤15 words. |
| **2. Rapid Tension Buildup** | 3–20 s | Stack 2–3 escalating details, each more impossible-sounding than the last. Specific numbers. No explaining yet. Each sentence ≤12 words. |
| **3. The Pivot** | ~20 s | Begin this section with the exact phrase **"You see,"**. Tension breaks; the explanation starts. Tell it as a story (a person, a decision, a cause → effect), not a list. |
| **4. The Final Twist** | last 5–8 s | One last surprising outcome. End abruptly on it — no "follow for more," no summary — so the loop back to the opening feels seamless. Ideally the last line connects back to the first line. |

## Step 3 — Writing rules
- One idea per sentence; short, spoken, punchy. Read aloud.
- Specific numbers over vague words; familiar comparisons for scale.
- "You see," appears exactly once, at the pivot.
- Visual change every 1–2 s; on-screen text for every key number.
- No CTA inside the script. A pinned comment or caption can carry it.

## Step 4 — Output format
A three-column table: `Time | VISUAL (on screen) | NARRATION (spoken)`, with parts tagged `[PARADOX]`, `[TENSION 1/2/3]`, `[PIVOT]`, `[TWIST]`. Then:
- On-screen caption text (big words to burn in)
- Word count and estimated runtime
- Self-check: paradox in ≤3 s? 2–3 escalations? "You see," at the pivot? Twist in the last 8 s? Loops cleanly?
- 3 title options (≤50 characters) and 5 hashtags

Save as `<topic>-short.md` in the user's `Desktop\Youtube channel` folder (inside the topic's subfolder if one exists), unless they say otherwise.

## When animating a Short
Follow the script verbatim: every row becomes a shot at its exact timestamp, and the animation length equals the script length.
